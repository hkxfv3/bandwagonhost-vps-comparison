## 常见问题

**问：20G CN2 GIA-E 和同价位的香港套餐怎么选？**
两者年付只差几十美元（169.99 对 899.99 除外，那是香港入门档的年付价），但实际差了整整一个档位。月付 89.99 美元的香港套餐延迟更低、流量更少（500GB/月）；年付 169.99 的 GIA-E 是 1TB 流量、可以在多机房切换。除非你明确需要香港节点的物理延迟，否则 GIA-E 的综合性价比更高。

**问：套餐以后能升级吗？**
可以。KiwiVM 面板支持套餐之间的升降级，流量和配置按比例折算，不用退掉重买。所以入门档买小了并不致命。

**问：30 天内不满意能退款吗？**
官方政策是新购订单（不含续费）在下单 30 天内可以申请退款，不同套餐的退款方式（原路退回或余额）以官方服务条款为准，下单前值得花两分钟读一遍。

**问：优惠码以后会变吗？**
会。搬瓦工的循环折扣码隔一段时间会换新码，旧码失效后新码力度通常维持在 6% 上下。结账前搜一下最新的搬瓦工优惠码，是成本最低的省钱动作。
